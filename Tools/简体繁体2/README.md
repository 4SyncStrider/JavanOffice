# Chinese converter

This tool converts between Simplified and Traditional Chinese using OpenCC.

## Features

- Simplified → Traditional conversion
- Traditional → Simplified conversion
- Copy output to clipboard
- Clear input and output controls
- Basic status feedback for empty and converted content

## Files

- index.html: converter structure and controls
- style.css: layout and theme styling
- script.js: conversion logic, status messages, and clipboard actions

## Notes

The conversion is practical for everyday text but may still need human review for very specific phrases, names, or complex terminology.
